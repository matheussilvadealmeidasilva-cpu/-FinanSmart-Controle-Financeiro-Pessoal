💰 FinanceFlow — Sistema de Controle Financeiro

Um sistema web de controle financeiro pessoal desenvolvido com React JS, que permite gerenciar receitas e despesas, acompanhar o saldo disponível e visualizar informações financeiras por meio de gráficos interativos.

O projeto tem como objetivo facilitar a organização financeira, proporcionando uma interface intuitiva, moderna e responsiva.

🚀 Funcionalidades

Interface de controle financeiro.

Cadastro de receitas.

Cadastro de despesas.

Listagem de movimentações financeiras.

Exclusão de transações.

Cálculo automático do saldo.

Resumo de receitas e despesas.

Gráfico de gastos por categoria.

Gráfico comparativo de receitas e despesas.

Histórico financeiro mensal.

Armazenamento de dados no LocalStorage.

🛠️ Tecnologias utilizadas

React JS: construção da interface e componentes.

JavaScript: lógica e funcionalidades.

CSS3: estilização e responsividade.

React Hooks (useState e useEffect): gerenciamento de estados e efeitos.

Recharts: criação de gráficos interativos.

LocalStorage: armazenamento de informações no navegador.

Lucide React: biblioteca de ícones.

📊 Gráficos financeiros

O sistema contará com gráficos dinâmicos para facilitar a visualização das movimentações:

Gráfico de categorias: apresenta a distribuição das despesas.

Gráfico de receitas e despesas: compara os ganhos e gastos.

Gráfico de evolução mensal: acompanha o comportamento financeiro ao longo do tempo.

Os gráficos serão atualizados automaticamente conforme as movimentações forem cadastradas ou removidas.

⚙️ Como executar o projeto

1. Clone o repositório:

git clone URL_DO_REPOSITORIO

2. Entre na pasta:

cd FinanceFlow

3. Instale as dependências:

npm install

4. Execute o projeto:

npm run dev

5. Acesse no navegador:

http://localhost:5173
